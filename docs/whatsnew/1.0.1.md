New Features

* 录制器新增实时视频画面(探屏从每步 5s 降到 0.2s),并支持随时点击"停止录制"
* 录制器探屏前自动核对手机当前前台 App,发现不是左栏选中的目标会自动切换
* 场景库新增"跟随设备"模式:不预先装机,执行时现查真机已装版本
* 执行台/执行记录用例卡片新增跳转按钮,直达对应执行的证据页

Bug Fixes

* 修复 dmg 安装后打开报错"adb 不可用"(Finder 打开的 App 现在能自动找到 adb)
* 修复固化回归脚本在切换设备信息读取方式后读不到入口文案的问题
* 修复证据页缩略图条在部分场景下的布局抖动
* 修复多设备场景下 Doc 报告身份归因错乱的问题
* 修复输入框 reset 时偶发乱码的问题

Improvements

* 设备列表加载提速,切回执行台从 850ms 降到 18ms
* 同一台设备录制和跑回归互斥,避免两边抢占导致失败
* 探屏默认自动清除广告全屏页(可关闭)
* 多语言表改为按设备实装版本自动建表,不用手动选版本
