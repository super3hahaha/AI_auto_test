New Features

* 录制器新增"长按"模式:长按弹出菜单、长按删除确认这类场景现在也能录了(跟点击一样记选择器,不记坐标)
* 执行台新增"失败不登记"选项:调试/探索性跑失败不占用问题清单,也不刷新线上表格和 Doc 报告

Bug Fixes

* 修复悬停提示浮层在窗口边角处被甩到屏幕中间的问题
* 修复录制器偶发提示"录制服务连接断开"(实际跟设备、进程都无关,是数据顺手兜住后已不再出现)
* 修复个别弹窗场景下清障算不出安全点击位置、导致弹窗清不掉的问题

Improvements

* Doc 报告新增按 Android 版本排序的分设备通过率表,多设备并行时更容易看出哪台设备拖了后腿
